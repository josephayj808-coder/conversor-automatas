Compilador y Optimizador de AutómatasEste proyecto implementa una canalización completa de compilación matemática que transforma expresiones regulares en autómatas finitos funcionales. Construido con Python y Streamlit, el sistema modela visual e interactivamente la transición teórica desde el no-determinismo puro hasta la minimización determinista absoluta, fundamentándose en las demostraciones formales del texto "Autómatas".   Arquitectura y Módulos CoreEl motor de conversión se divide en fases de procesamiento algorítmico que operan de forma secuencial:Analizador Léxico y Sintáctico (Parser): Emplea un filtro de seguridad estricto y el algoritmo de Shunting Yard para transformar la notación humana (infija) a notación de máquina (postfija), resolviendo la precedencia de operadores matemáticos de forma lineal.AFN-$\lambda$ (Construcción de Thompson): Modela la demostración constructiva del Teorema de Kleene. Parte I, conectando mini-autómatas mediante transiciones espontáneas. Incluye un selector de modo para aplicar la construcción académica clásica o una optimización por fusión de estados en las concatenaciones.AFN Canónico (Sin $\lambda$): Ejecuta el Teorema 2.7.1 calculando la $\lambda$-clausura ($\Lambda[q]$) de cada vértice para redireccionar los vectores de lectura reales, eliminando las transiciones vacías mientras se preserva el lenguaje original.Determinización (Subconjuntos): Transforma el autómata no determinista en un AFD basándose en el Teorema 2.5.1. Agrupa las ramificaciones simultáneas en "macro-estados", erradicando el no-determinismo computacional.Minimización (Algoritmo de Moore): Ejecuta particiones iterativas de estados equivalentes basándose en sus firmas de transición. Los vértices indistinguibles se fusionan para garantizar la máquina de estados finitos más económica posible, complementada con un motor de simulación de cadenas en tiempo real.
